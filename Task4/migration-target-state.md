# Образ целевого результата миграции данных (To-Be через 12 месяцев)

В данном документе зафиксировано финальное целевое состояние ИТ-ландшафта и критерии успешности завершения миграции данных интегрируемого банка RetailBank в контур FinUnion.

## 1. Спецификация целевого состояния перехода

| Вопрос | Что описать (Целевой результат через 12 месяцев) |
| :--- | :--- |
| **Какие системы остаются** | Единые централизованные системы FinUnion: `FU CRM`, `Core Banking (FU Core)`, `FU Loans`, единый карточный процессинг, центральный `MDM Customer Hub`, аналитическое `DWH` и `Data Lakehouse` (S3 + Iceberg + Trino) [1.1]. |
| **Какие выводятся из эксплуатации** | Все legacy-системы поглощаемого банка RetailBank: `RB CRM`, `Core Banking RetailBank`, `Loan System RetailBank`, `Card Processing RetailBank`, а также их локальные хранилища данных и серверы отчетности [1.1]. Лицензии аннулируются, железо выключается (Decommissioning). |
| **Какие данные мигрируются** | **1. Активный операционный портфель:** Действующие клиенты (ФЛ/ЮЛ), открытые 20-значные счета, остатки на вкладах, активные карты и непогашенные кредиты мигрируют в целевые базы `FU Core / Loans`. <br>**2. Исторический архив (Big Data):** Закрытые договоры, пятилетняя история проводок, логи кликстрима и технические логи legacy-систем мигрируют строго в **Data Lakehouse (S3)** для нужд моделей ИИ и ретроспективного анализа [1.1]. |
| **Какие потоки переключаются** | Все каналы обслуживания (отделения, банкоматы, мобильные приложения) переключаются на единую шину **Apache Kafka** и оркестратор **Apache Airflow** FinUnion [1.1]. Онлайн-регистрация анкет переводится на синхронные API-запросы к единому **MDM FinUnion** для мгновенного исключения дублей во фронт-офисе [1.1]. |
| **Какие критерии подтверждают завершение перехода** | **1. Технический критерий:** Legacy-серверы полностью обесточены; новые аналитические витрины (Data Products) доменов РБ, МСБ, Рисков и КЦ успешно развернуты и функционируют на базе Lakehouse/DWH [1.1].<br>**2. Финансовый критерий (Data Reconciliation 100%):** Сумма всех балансов и кредитных остатков, выгруженных из RetailBank, до копейки совпала с данными, зачисленными в FinUnion. Потери данных отсутствуют.<br>**3. Регуляторный критерий:** Объединенный банк успешно сформировал и сдал первую сводную отчетность Главной книги в ЦБ РФ, и регулятор принял её без замечаний. |
