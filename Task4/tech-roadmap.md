# Технологическая дорожная карта (Technology Roadmap)

В данном документе представлена целевая технологическая дорожная карта аналитической платформы объединенного банка через 12 месяцев, оформленная в соответствии с методологией **Technology Radar**.

## 1. Таблица технологических зон (Technology Radar Matrix)

| Зона | Что включить (Компоненты стека) | Обоснование интеграции и выбора технологии |
| :--- | :--- | :--- |
| **Adopt** *(Внедрить и масштабировать)* | • Центральный модуль `MDM Customer Hub`<br>• Оркестратор `Apache Airflow`<br>• Классическое реляционное `DWH`<br>• Каталог данных `DataHub` [1.1] | Данные компоненты успешно прошли жесткую проверку в рамках 3-месячного MVP и доказали свою операционную надежность [1.1]. Команда инженеров полностью владеет этим инструментарием, риски внедрения отсутствуют. Технологии масштабируются на весь объединенный банк как официальный enterprise-стандарт для ведения Главной книги, сдачи отчетности в ЦБ РФ и ведения карт происхождения данных (Data Lineage) [1.1]. |
| **Trial** *(Испытать в бою / Пилотировать)* | • Объектное хранилище `S3`<br>• Табличный формат `Apache Iceberg`<br>• Распределенный вычислительный движок `Trino` [1.1] | Данный высокотехнологичный Big Data стек развернут в рамках целевого **Data Lakehouse** для хранения петабайтных исторических архивов и логов кликстрима [1.1]. Компоненты находятся в зоне **Trial** (опытно-промышленная эксплуатация), так как являются новыми для ИТ-команды банка. Требуется боевая обкатка кластеров под пиковыми нагрузками, оптимизация федеративных SQL-запросов и мониторинг рисков перегрузки сети [1.1]. |
| **Assess** *(Оценить на перспективу)* | • Полноценная децентрализованная архитектура `Data Mesh` (с разделением ИТ-команд разработки и баз данных по каждому отделу) [1.1] | На текущем этапе слияния банк внедрил исключительно организационные элементы Mesh (концепцию Data Products и роли бизнес-владельцев данных по департаментам из условий ТЗ) [1.1]. Запускать полноценный технологический Data Mesh во всей организации сейчас преждевременно из-за кадрового хаоса и гигантских затрат. Подход отнесен в зону **Assess** для долгосрочного изучения (горизонт 2–3 года) [1.1]. |
| **Hold** *(Приостановить и выключить)* | • Legacy-системы интегрируемого банка (`RB CRM`, `Core Banking RetailBank`, кредитные модули)<br>• Старое локальное `DWH RetailBank`<br>• Интеграционные паттерны «точка-точка» [1.1] | На данные компоненты накладывается жесткое вето, любое их развитие запрещено. Переходный "период охлаждения" (Read-Only доступ для сотрудников на 1–2 месяца для адаптации) завершен, а старая база DWH законсервирована после перекачки архивов [1.1]. Системы подлежат полному физическому отключению (Decommissioning) для снижения ИТ-затрат и обеспечения единой точки правды (Single Source of Truth) [1.1]. |
