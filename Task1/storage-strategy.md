## 3. Распределение сущностей по типам целевых хранилищ

Для эффективного разделения операционной (OLTP) и аналитической (OLAP) нагрузки, а также централизованного управления мастер-данными, сущности распределены по следующим типам хранилищ:

| Сущность | Рекомендуемый тип хранилища | Архитектурное обоснование выбора |
| :--- | :--- | :--- |
| **Party Data Management (Единый ID)** | **MDM** | Специализированный модуль для очистки, дедупликации и создания «золотого профиля» клиента FinUnion + RetailBank. |
| **Клиент** | **OLTP БД** (фронт) + **MDM** (склейка) + **DWH** (аналитика) | Рождаются в CRM/АБС, проходят сквозную идентификацию в MDM, а затем в очищенном виде доступны в DWH для построения клиентской аналитики. |
| **Счёт / Карта / Договор** | **OLTP БД** (операции) + **DWH** + **Data Lakehouse** | Операционная жизнь и быстрые апдейты происходят в OLTP. Текущие срезы для отчетности хранятся в DWH, а долгосрочный архив изменений — в Data Lakehouse. |
| **Платёж (Бизнес-операция)** | **OLTP БД** (инициация) + **Data Lakehouse** | Высокоинтенсивный поток клиентских действий. Чтобы не перегружать DWH миллиардами записей, история платежей сгружается в Lakehouse (S3 + Iceberg) для поведенческого BI. |
| **Транзакция (Проводка в АБС)** | **OLTP БД** (учет) + **DWH** | Бухгалтерские проводки Главной книги требуют 100% точности. Из OLTP они улетают в DWH для формирования регламентированной отчетности перед ЦБ РФ. |
| **Банковский продукт (Тариф)** | **MDM** (справочник) + **DWH** | Продуктовый каталог и тарифные сетки выступают в роли нормативно-справочной информации (НСИ), централизованно ведутся в MDM и маппятся в DWH. |
| **Обращение клиента** | **OLTP БД** (CRM) + **Поисковый движок** + **DWH** | Тексты жалоб индексируются в Поисковом движке (Elasticsearch) для мгновенного поиска операторами колл-центра, а метрики (SLA, объемы) агрегируются в DWH. |
| **Сотрудник банка / Отделения** | **MDM** (справочник) + **DWH** | Классические условно-постоянные справочники. Мастер-данные консолидируются в MDM, история кадровых изменений и география продаж анализируются в DWH. |
